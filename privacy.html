Privacy Policy

Anatolian Folk Channel Manager · Last updated: 26 October 2026

1. Who uses this application

Anatolian Folk Channel Manager ("the application") is a private, internal tool. Its only user is the owner of the YouTube channels it manages. It is not available to the public and does not offer accounts or sign-up to anyone else.

2. YouTube API Services

The application uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the application, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data is accessed

Through OAuth 2.0, the owner authorizes the application to access only the YouTube channels that he owns. The application accesses:

  • Metadata of the owner's own videos and playlists (titles, descriptions, tags, thumbnails, localizations).
  • Aggregated YouTube Analytics reports for the owner's own channels (for example views, watch time, click-through rate).
  • Public comments posted on the owner's own videos, in order to reply to them.

The application does not access any channel, video or account that the owner does not own, and does not collect personal data about viewers beyond the public comment text and public display name that YouTube provides with each comment.

4. How data is used

Data is used only to manage the owner's channels: localizing and optimizing video metadata, uploading the owner's own content, replying to comments, organizing playlists and measuring results.

5. Storage and retention

Data is stored only locally on the owner's personal computer (a local database and backup files of previous metadata). Nothing is stored on external servers by this application. Comment data and analytics are kept only as long as needed for these purposes; YouTube API data is refreshed or deleted in line with the YouTube API Services policies (stored API data is not kept for more than 30 days without being refreshed).

6. Sharing

No data is sold, shared, or transferred to any third party.

7. Cookies

The application does not use cookies, trackers or advertising identifiers. This website does not use cookies either.

8. Revoking access

Access granted to the application can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
